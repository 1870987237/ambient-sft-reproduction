# 16 GB 单卡上的 Ambient SFT 复现实验报告

我们在一张 RTX 5070 Ti 上实现了 Ambient SFT 的固定温度训练流程，并用论文同款 Qwen3-1.7B-Base 跑完了全参数对照。同款底座的数学分接近论文，差距在微调后扩大。在本机这轮 1.7B 实验里，两种蒸馏都提高了数学分，常温蒸馏在两项评测上都比升温后的 Ambient SFT 得分高。 [1.7B 原始结果](qwen3-1.7b-results.md) · [论文表 2](https://arxiv.org/html/2611.23229v1#S4.SS3)

## 实现与实验过程

普通 SFT 用标注答案训练学生。蒸馏组额外使用冻结的底座作为教师。每个微批次以 75% 的概率做普通 SFT，其余微批次让师生阅读同一段训练文本，在相同的 assistant 下一 token 位置匹配全词表分布。常温蒸馏取 `T=1`，Ambient SFT 取 `T=2.5`。温度作用在两边的 logits 上，匹配损失采用论文伪代码的软标签交叉熵。两组蒸馏在同一种子下使用相同的随机分支。1.7B 实验中，两组恰好在相同的 486 步做教师匹配。 [训练实现](../../scripts/train.py) · [论文算法 1](https://arxiv.org/html/2611.23229v1#A2)

1. 用 0.6B 跑 12 步，确认两个训练分支、损失掩码和冻结教师能工作。
2. 把 0.6B 扩到 512 步，跑完整评测，再用同一批检查点对比两种 IFEval 输出预算。
3. 固定 Dolci-Instruct-SFT 的一个数据版本和分片，取 4,000 条训练候选及 256 条留出样本。输入截断到 384 token 后，分别有 3,390 条和 226 条保留了受监督位置。0.6B 的三组方法各跑三个种子，每组 2,048 步。
4. 换成论文同款 Qwen3-1.7B-Base，先测原始底座，再用同一份数据、种子和顺序跑三组全参数微调。学生使用 BF16 权重和 8-bit AdamW 优化器状态。冻结教师放在系统内存，需要计算教师预测时才把权重临时复制到显卡。

数据划分、输入文件校验值、训练命令和评测版本均可查。 [冻结数据与评测协议](local-benchmark-protocol.md) · [1.7B 训练配置](qwen3-1.7b-protocol.md)

## 本机设置与论文设置

| 项目 | 本机 1.7B 对照 | 论文 1.7B 指令微调 |
| --- | --- | --- |
| 起点 | Qwen3-1.7B-Base | Qwen3-1.7B-Base |
| 训练数据 | 4,000 条 Dolci 候选，每组实际训练 2,048 个样本 | 21,503 条 Dolci 样本，训练 10 轮 |
| 每次优化器更新 | 1 个样本，输入最多 384 token | 全局批量 1,048,576 token，序列长度 32,768 token |
| 优化器 | AdamW，8-bit 状态 | AdamW |
| 硬件 | 1 张 RTX 5070 Ti，16 GB 显存 | 16 张 GH200 |

两边的峰值学习率都是 `8e-5`，前约 3% 步数线性预热，之后线性衰减。本机普通 SFT、常温蒸馏、Ambient SFT 的训练循环耗时分别约 **9.0、12.5、12.8 分钟**，模型加载、保存和评测另计。两种蒸馏的峰值分配显存都约 **11.3 GiB**，PyTorch 峰值预留约 **11.5 GiB**。 [训练日志汇总](qwen3-1.7b-results.json) · [论文附录 C.2](https://arxiv.org/html/2611.23229v1#A3.SS2)

## 实测结果

IFEval 测 541 道指令题，按提示级宽松通过率计分。GSM8K 测 1,319 道数学题，使用 OLMES 的八个固定示例，按最终答案精确匹配计分。所有对照统一使用贪心生成，输出上限分别是 2,048 和 512 token。 [评测协议](local-benchmark-protocol.md)

| 方法 | 0.6B IFEval（三种子均值） | 0.6B GSM8K（三种子均值） | 1.7B IFEval（种子 42） | 1.7B GSM8K（种子 42） |
| --- | ---: | ---: | ---: | ---: |
| 原始底座 | — | — | 34.38% | 52.24% |
| 普通 SFT | **24.46%** | 5.56% | **47.32%** | 52.31% |
| 常温蒸馏 `T=1` | 22.18% | 4.80% | 38.26% | **57.39%** |
| Ambient SFT `T=2.5` | 21.01% | **6.09%** | 35.49% | 56.94% |

在 1.7B 对照中，Ambient SFT 相比普通 SFT 多答对 **61 道数学题**，少通过 **64 道指令题**。同一套蒸馏步骤下，`T=2.5` 相比 `T=1` 少答对 **6 道数学题**，少通过 **15 道指令题**。对同一批题做配对抽样后，后两项差异的 95% 区间都包含零。这些区间反映题目波动，1.7B 的训练种子波动仍待测量。 [1.7B 配对统计](qwen3-1.7b-results.json)

**0.6B 的数学增益小，且随种子变化。** 2,048 步的对照中，Ambient SFT 相比普通 SFT 的 GSM8K 平均高 **0.53 个百分点**，三次中两升一降。IFEval 平均低 **3.45 个百分点**，三次都下降。 [0.6B 逐种子结果](ambient-sft-2048.md)

**评测给模型多少输出空间也会影响观察。** 在早期 0.6B 的 512 步检查点上，把 IFEval 输出上限从 2,048 调到 512 token 后，Ambient SFT 相对普通 SFT 的优势从 **3.33 降到 1.85 个百分点**，短预算下的配对区间包含零。因为两种预算是分别生成的，Ambient SFT 有一部分回答连前缀也发生了变化。 [输出预算对照](ifeval-output-budget.md)

## 与论文结果的差距

同款 1.7B 原始底座在本机的 GSM8K 是 **52.24%**，和论文的 **53.5%** 相差 **1.26 个百分点**。微调后，论文的普通 SFT 升到 **61.0%**，本机的普通 SFT 到 **52.31%**，只多答对了一题。差距在普通 SFT 阶段已经出现。本机 Ambient SFT 相比普通 SFT 在数学上提高 **4.62 个百分点**，论文对应结果是 **11.3 个百分点**。两边的训练数据量、序列长度、批量和优化器状态精度都有差异，各因素的影响仍待单独验证。 [本机与论文对照](qwen3-1.7b-results.md) · [论文表 2](https://arxiv.org/html/2611.23229v1#S4.SS3)

这份报告覆盖**固定温度的单卡指令微调**。在实测的硬件和配置下，1.7B 全参数训练可运行，蒸馏相对普通 SFT 提高了数学分，升温的额外收益仍缺少证据。论文中的按数据来源调温、领域适配与推理微调仍待本机验收。 [项目验收范围](../../PLAN.md) · [论文 §4 与附录 D.5](https://arxiv.org/html/2611.23229v1)
